# SmartCampus

SmartCampus is a Python Full Stack Student Management and Performance Platform.

It allows educational institutions to manage students, academic marks, attendance, results, and performance through a modern web application.

## Features

- Student registration and management
- Add, edit, view, and delete students
- Student search
- Academic marks management
- Attendance management
- Automatic percentage calculation
- Grade calculation
- Student results
- Dashboard with academic statistics
- User login and authentication
- Protected application pages
- Form validation
- REST API integration
